# P1 严格读数审计

评测对象为已通过无泄露前置校验的18条P1用户证据样本。该审计未修改P0v5数据库、P1检索逻辑或现有正式报告。

## 结果

- 用户证据 Recall@1：0.8333，15／18。
- 用户证据 Recall@3：0.9444，17／18。
- 用户证据 Recall@8：1.0，18／18。
- 用户证据 MRR：0.8968。
- Gold最终排名分布：第1位15条，第2位2条，第7位1条。
- 授权证据 Recall@8：1.0，18／18。
- 跨组织泄漏率：0，18／18条禁止组织Gold均未返回。

## 结论边界

本轮排除了完整问题和非白名单连续八字符命中，故不再存在此前确认的直接文本泄露。

但当前18条Gold均继承自P0v5，且P1库内286条用户证据没有可用原始文件名。该数据不能证明面对未参与P0v5的新来源文档时的泛化能力。因而Recall@8和授权证据Recall@8为1.0只能解释为当前同来源、八条上下文预算下的覆盖情况，不能作为发布能力结论。

下一轮独立来源评测需要未参与P0v5的新文档、文档来源标识、人工确认的Gold Chunk绑定，以及与Gold同组织同Proposal的困难干扰证据。评测主指标应为Recall@1、Recall@3和MRR，Recall@8仅作上下文覆盖指标。
