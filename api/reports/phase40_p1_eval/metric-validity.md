# P1 指标有效性审计

## 结论

P1 已完成受控双域查询拆分。用户证据 Context Recall@8 和授权证据 Recall@8 的 1.0 不具备检索质量解释力，不得作为 P1 或发布门禁的通过依据。

## 证据

- P0v5 语料就绪报告记录18条用户证据查询泄露观察，规则侧观察数为0。
- 用户证据评测问题逐字出现在对应 Gold 原文块中。
- 跨组织种子为验证组织范围隔离，将评测问题写入授权与禁止组织的同义测试证据正文。

## 仍然有效的结论

- 跨组织泄漏率为0，18条可运行样本均未返回禁止组织证据。这仅证明组织范围过滤有效。
- 规则 RAG 的 P0v5 结果不受本审计影响。

## 重测条件

- 新问题必须是人工确认的改写文本，不得作为连续字符串出现在 Gold 原文、标题、结构化事实或种子描述中。
- 必须在独立于 P0v5 的 P1 用户证据评测夹具上运行。
- 报告应分别给出查询泄露观察数、Context Recall@8、授权证据 Recall@8 和跨组织泄漏率。
