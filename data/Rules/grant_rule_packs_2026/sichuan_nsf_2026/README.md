# 2026年四川省自然科学基金规则包

## 覆盖范围

本包覆盖重大、重点、面上、创新研究群体、青年科学基金A类和青年科学基金B类六类项目，并包含西南民族大学在省级指南名额表中的公开限额覆盖层。

## Agent使用建议

1. 创建项目时必须先选择具体类别，禁止用同一套资格规则处理六类项目。
2. 规则RAG先按类别、年份、单位和指南方向过滤，再进行检索。
3. 资格校验应覆盖年龄、学历职称、历史主持项目、个人年度限项和单位限额。
4. 所有支撑材料需建立RuleEvidence或UserEvidence来源记录。
5. 系统模板和依托单位内部截止时间需要用户补充，不得仅依赖本公开包。
