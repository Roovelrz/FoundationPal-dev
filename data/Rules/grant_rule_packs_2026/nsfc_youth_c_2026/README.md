# 2026年国家自然科学基金青年科学基金项目C类规则包

## 规则包定位

本包用于约束2026年度青年科学基金项目C类的资格预检、材料收集、章节规划、证据核验和形式审查。公开来源完整度较高，但正式申请书空白模板仅在科学基金网络信息系统中提供，因此系统必须允许用户补充当年系统模板和依托单位内部通知。

## 核心参数

| 项目 | 规则 |
| --- | --- |
| 集中接收 | 2026年3月1日至3月20日16时 |
| 正文结构 | 立项依据、研究内容、研究基础 |
| 正文篇幅 | 原则上不超过30页 |
| 研究期限 | 3年，系统自动生成 |
| 经费方式 | 包干制，申请时无需编制预算 |
| 平均资助强度 | 30万元/项 |
| 男性年龄 | 未满35周岁，1991年1月1日及以后出生 |
| 女性年龄 | 未满40周岁，1986年1月1日及以后出生 |

## Agent使用建议

1. 先运行资格校验，再允许进入章节规划。
2. 规则RAG只检索本包及当前科学部补充包。
3. 用户资料RAG负责论文、项目、实验和研究基础证据。
4. Writer不得直接生成无法由用户资料支撑的成果、数字和角色信息。
5. 生成式人工智能使用声明应进入最终形式审查清单。
6. 创建项目时要求用户上传当年系统导出的申请书模板，以消除系统字段更新风险。
