# 2026年四川省专项教改规则包及西南民族大学补充层

## 完整度说明

本包已经覆盖四川省教育厅层面的申报方向、项目类别、负责人和成员限项、重复申报、建设周期、材料名称及核心质量要求。西南民族大学校级通知教务函〔2026〕82号未在公开网页中取得全文，因此本包的组织补充层处于待补齐状态，不能直接宣称为完整西南民族大学规则包。

## 七类选题方向

1. 高等教育发展战略与区域协同创新
2. 产教融合、科教融汇与特色学院建设
3. 人才培养模式与教育评价综合改革
4. 人工智能赋能教育教学改革创新
5. 专业课程教材一体化与教学质量保障
6. 教师教学能力发展与思政育人创新
7. 其他具有改革创新价值的选题

## 已确认的硬规则

| 项目 | 规则 |
| --- | --- |
| 负责人 | 高校在岗教师或管理人员，同一负责人限报1项 |
| 项目组成员 | 含负责人同期参与本类项目不超过2项 |
| 重复申报 | 近3年相近立项无重大创新原则上不予立项 |
| 周期 | 2年，可延期1年，总周期不超过3年 |
| 目标 | 必须可量化、可考核，并形成任务清单 |
| 材料 | 申报书、汇总表，网上申报阶段可能需要联络人表 |

## 西南民族大学必须补充的内部文件

1. 教务函〔2026〕82号全文
2. 校内申报书附件
3. 校内汇总表和限额分配表
4. 校内截止时间和材料报送方式
5. 意识形态、保密、师德师风及伦理审核表
6. 后续网上申报通知

在上述文件未上传前，Agent可以辅助规划和撰写，但必须显示校内规则未完成核验，不得给出确定的西南民族大学截止时间或推荐名额。
