# Phase 3.0 公开 AMR 证据包

本包包含18篇公开可查的AMR论文PDF及核验JSON。所有资料仅作为外部公开测试证据，所有权和成果归属保持为论文作者。

## 使用边界

- 可用于文件上传、PDF解析、Chunk生成、RAG检索、Citation核验、权限隔离和评测。
- 不得表述为申请人或组织发表的论文、完成的项目、拥有的知识产权或实验室私有数据。
- 旧02与04基于原开发事实构建，不能与本证据包直接混用。
